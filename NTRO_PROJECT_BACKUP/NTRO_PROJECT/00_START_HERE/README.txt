NTRO PROJECT - FILE GUIDE
=========================

START HERE:
Open FILE_INDEX.csv to search for a filename and see its folder.

FOLDER GUIDE:

01_FINAL_DELIVERABLES
Final analysis ZIP and the individual analysis-ready files.

02_RAW_DATA
Original source files retained for future processing.
The original FIRMS download archives must be copied here separately
if they are still available in your Colab session.

03_CLEANED_DATA
Merged FIRMS datasets and the current facility inventory.

04_ANALYSIS_RESULTS
Grid, persistence, facility-distance and seasonal analysis outputs.

05_FACILITY_REVIEW
WRI reconciliation files, OSM review candidates and the older
facility inventory. These are retained for review, not assumed redundant.

IMPORTANT:
- Files in this archive are copies; originals in /content are not deleted.
- Missing files are listed in the output of the notebook.
- This backup only includes files found and copied by the script.
- The final analysis package does not replace the full FIRMS datasets.
- Source classification remains unknown unless independently established.
- Facility proximity does not prove that a thermal detection came from
  that facility.
